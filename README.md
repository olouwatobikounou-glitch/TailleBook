## ✨ Fonctionnalités

| Feature | Statut | Description |
|---|---|---|
| 🔐 **Auth** | ✅ | Inscription / connexion email + mot de passe (Firebase Auth) |
| 🏠 **Feed** | ✅ | Posts, stories, composer, likes |
| 🔥 **Pubslook** | ✅ | Feed vidéo vertical type TikTok avec FYP algorithmique |
| 🎁 **Gifts** | ✅ | Catalogue de cadeaux animés (Rose → Fusée) |
| 💬 **Commentaires** | ✅ | Bottom sheet temps réel par vidéo |
| 📤 **Upload** | ✅ | Upload vidéo Firebase Storage (coût : 200 F) |
| 🌍 **Traduction** | ✅ | 4 langues : Français, English, Fon, Yoruba |
| 💰 **Balance** | ✅ | Système de solde virtuel (crédit/débit par interaction) |
| 🔔 **Notifications** | ⏳ | À venir (FCM) |
| 👥 **Amis** | ⏳ | À venir |
| 🛒 **Market** | ⏳ | À venir |
